# 電脳せどり運用基盤（sedori-ops）

作成日: 2026-09-28（日本時間）

## 1. この基盤でできること・できないこと

| 区分 | 内容 |
|---|---|
| できる（エージェントが担当） | 市場・商品リサーチの実行と利益試算、仕入れ判断材料の整理、出品文面の作成と法令チェック、取引・在庫・損益の記録と集計、購入者・出品者・仕入れ先への連絡文面の作成、日次/週次/月次ルーチンの進行管理 |
| できない（人間＝事業主が担当） | 仕入れの発注と支払い、出品の確定操作、発送、返金・キャンセルの確定、アカウント開設・本人確認、税務申告、各プラットフォームへのログインを伴う操作 |

理由は2つあります。
- 発注・支払い・出品確定は法的責任と金銭が動く行為で、事業主の意思決定として残す必要がある。
- 主要プラットフォーム（Amazon・メルカリ・楽天など）はアカウント操作の自動化や規約外のデータ取得を制限しており、違反するとアカウント停止で事業が止まる。

## 4. 使い方（最短ルート）

1. `routines/onboarding_checklist.md` を上から埋める（アカウント、許認可、資金、ツール契約）。
2. `config/business.yaml` を自分の条件に書き換える（資金、目標利益率、扱うカテゴリ、手数料率の確認日）。
3. Claude Code で以下を実行する。
   - `/sedori-research <カテゴリや仕入れ先>` … 候補を出して `data/candidates.csv` に追記
   - `/sedori-listing <候補ID>` … 出品文面を作成
   - `/sedori-contact <状況>` … 連絡文面を作成
   - `/sedori-daily` … 日次ルーチン（承認待ち、価格改定、未返信、在庫）
4. 発注・出品・発送は事業主が実行し、結果を `data/*.csv` に反映する（trader に「発注した」と伝えれば記録します）。

## 5. 前提（この基盤が採用している初期設定）

事業主から未確認のため、以下を初期値としています。変更は `config/business.yaml` で行ってください。

- 販売先: Amazon.co.jp（FBA）を主、ヤフオク!/Yahoo!フリマを副。メルカリは **メルカリShopsの出店審査に通った場合のみ**。個人アカウントでの事業出品は2025年10月22日の規約改定で禁止（`docs/00_facts_and_sources.md` 参照）。
- 仕入れ先: 国内EC（メーカー公式、家電量販店EC、Yahoo!ショッピング、楽天市場、ポイント還元セール）。海外仕入れ（輸入）は対象外。
- 取扱: **新品のみ**からスタート。中古品は古物商許可取得後に解禁。
- 商品カテゴリ: 出品規制が少なく、回転が読みやすい「日用品・家電アクセサリ・ホビー（規制外）・書籍以外のメディア除く」を初期候補。医薬品、酒類、食品、コスメ（要確認）、ブランド品は初期対象外。
- リサーチデータ源: Keepa（有料プラン）。契約していない間はリサーチ精度が大きく落ちるため、`business.yaml` の `tools.keepa.enabled` を false にすると researcher が「目視確認モード」で動く。

## 6. 既知のリスク（開始前に必ず読む）

詳細は `docs/01_compliance.md`。要点のみ。

1. **アカウント停止リスク**: Amazonの真贋調査・出品規制、楽天の転売目的購入の禁止、メルカリの事業者利用禁止。
2. **法令**: 古物営業法（中古品）、特定商取引法（表示義務）、景品表示法（誇大表示）、消費税（インボイス判断）、所得税（申告）。
3. **収益性**: 2026年4月1日からAmazon販売手数料が0.4pt引き上げ。薄利案件はこの改定で赤字化しうる。価格競争・値崩れ・返品率も利益を直撃する。
4. **ツール費用**: Keepa API を使う外部ツール開発者向けに年額課金が導入（2026-01-31〜、$1,400/年と報じられている）。個人の通常利用プランと混同しないこと。
5. **キャッシュフロー**: FBA入金は約2週間サイクル。仕入れ資金が寝る期間を `business.yaml` の `capital` で管理する。
