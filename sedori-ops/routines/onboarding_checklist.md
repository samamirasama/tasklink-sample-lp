# 開業前チェックリスト

すべて事業主が実施。完了したら `business.yaml` の対応項目を更新する。

## 1. 意思決定（先に決める）

- [ ] 販売先の主軸（初期値: Amazon FBA）と副軸（ヤフオク!）を確定
- [ ] 新品のみで始めるか、中古も扱うか（中古なら古物商許可を先に取る。審査目安約40日）
- [ ] 仕入れ資金（`capital.total_jpy`）と月次目標（`targets`）を確定
- [ ] 扱うカテゴリ・扱わないカテゴリを確定（`research.categories_*`）
- [ ] 週に使える作業時間（リサーチ・梱包・納品）を見積もる

## 2. 法務・税務

- [ ] 開業届・青色申告承認申請（個人）
- [ ] 古物商許可（中古を扱う場合）
- [ ] 特定商取引法に基づく表示の内容確定（住所非公開が必要ならバーチャルオフィスの条件確認）
- [ ] インボイス登録の要否を税理士等に確認
- [ ] 会計ソフトと事業用口座・カードの準備

## 3. アカウント

- [ ] Amazon出品用アカウント（大口）開設、本人確認、特商法表示設定、銀行口座登録
- [ ] FBA利用設定、納品先・ラベル要件の確認
- [ ] ヤフオク!（Yahoo! JAPAN ID、出品者情報、事業者表示）
- [ ] メルカリShops 出店申請（審査に通らなければ `mercari_shops.enabled: false` のまま）
- [ ] 仕入れ先アカウント（家電量販店EC、Yahoo!ショッピング、楽天市場）。各規約の転売条項・数量制限を確認

## 4. ツール

- [ ] Keepa 有料プラン契約（契約後 `tools.keepa.enabled: true`）。API利用は料金体系を公式で確認してから
- [ ] 手数料率の実値をセラーセントラルで確認し、`referral_fee_by_category` と `fba_fees.sample.csv` に転記、`fee_rates_verified_on` を記入
- [ ] Python 3.10+ が実行できる環境（`scripts/` 用）

## 5. 物流

- [ ] 梱包資材（段ボール、緩衝材、FNSKUラベル用プリンタ）
- [ ] FBA納品の配送手段（集荷契約の有無）
- [ ] 自己発送分の配送方法と料金表
