# 法令・規約チェックリスト

`sedori-director` はすべての仕入れ・出品案件で本チェックを通し、1つでも NG があれば「保留」にする。
法律判断が必要な項目は、行政書士・税理士・弁護士への相談を事業主に促す（エージェントは法的助言をしない）。

## A. 開業前（1回だけ）

| # | 項目 | 判定 | 根拠・メモ |
|---|---|---|---|
| A1 | 開業届（個人）または法人設立 | ☐ | 税務署。青色申告承認申請も同時に検討 |
| A2 | 古物商許可（中古品を扱うなら必須） | ☐ | 管轄警察署。新品のみなら不要。`business.yaml: handles_used_goods` と整合させる |
| A3 | 特定商取引法に基づく表示の準備 | ☐ | 氏名・住所・電話番号。自宅非公開にしたい場合はバーチャルオフィスの条件を確認 |
| A4 | 消費税・インボイス方針 | ☐ | 免税事業者のまま始めるか、適格請求書発行事業者になるか。Amazonの購入者は法人も多い |
| A5 | 帳簿・証憑の保存方法 | ☐ | 仕入れ請求書（180日以内のものを規制解除で使う）を必ずPDF保存 |
| A6 | 事業用口座・カードの分離 | ☐ | 楽天カード等の規約でせどり仕入れ利用が問題視される事例あり。カード会社の規約を確認 |
| A7 | 各プラットフォーム規約の通読 | ☐ | Amazon出品規約・コンディションガイドライン、ヤフオク!ガイドライン、メルカリShops規約 |

## B. 仕入れ案件ごと

| # | 項目 | NGなら |
|---|---|---|
| B1 | 新品か？（消費者の手に渡っていないか。個人からの購入は古物） | 古物商許可がなければ見送り |
| B2 | 仕入れ先の規約に転売禁止・購入数量制限はないか | 見送り、または制限内の数量にする |
| B3 | メーカーが転売禁止を公表していないか | 見送り |
| B4 | Amazonで出品規制（ブランド・カテゴリ）がかかっていないか | 規制解除できる請求書が得られるか確認。得られなければ見送り |
| B5 | 禁止・要許可商材ではないか（医薬品、酒類、食品、化粧品の一部、電波法・PSE対象、危険物、チケット、金券、知財侵害品） | 見送り |
| B6 | 請求書・領収書が事業者名で発行されるか | 発行されなければ見送り |
| B7 | ポイント還元前提の利益でないか（`include_points_in_profit` に従う） | 保守的に再計算 |
| B8 | 資金ゲート: `max_per_sku_jpy` / `max_per_order_jpy` / `reserve_ratio` の範囲内か | 数量を減らすか見送り |

## C. 出品文面ごと（copywriter が実施、director が確認）

| # | 項目 |
|---|---|
| C1 | 景品表示法: 「最安」「No.1」「業界初」など根拠のない優良・有利誤認表示がないか |
| C2 | 薬機法: 効能効果をうたっていないか（日用品でも「殺菌」「治る」等） |
| C3 | 商標・著作権: メーカー画像・文章の無断転載をしていないか。並行輸入品なら明記 |
| C4 | コンディション表記: Amazonコンディションガイドラインに合致（新品＝未開封・保証書付きなど） |
| C5 | 特商法表示: 事業者情報が設定済みか |
| C6 | プラットフォーム固有の禁止: 外部誘導、連絡先記載、レビュー要求の対価提示 |

## D. 取引・連絡ごと（communicator が実施）

| # | 項目 |
|---|---|
| D1 | 個人情報の取り扱い: 購入者情報を目的外利用しない、他社ツールに貼らない |
| D2 | レビュー依頼: 対価提供・高評価の誘導をしない（Amazonは特に厳格） |
| D3 | 返品・返金: プラットフォームの規定に従い、独自条件を押し付けない |
| D4 | 真贋・偽物の指摘を受けたら即エスカレーション。自己判断で反論しない |

## E. 自動化の境界

| 行為 | 扱い |
|---|---|
| Keepa等の正規APIでの価格・ランキング取得 | 可（契約範囲内） |
| SP-API での自社在庫・価格の管理 | 可（開発者登録・規約遵守） |
| 販売サイトへのログインを伴う自動購入・自動出品・自動メッセージ送信 | 不可（各社規約違反リスク・アカウント停止） |
| 規約で禁じられたスクレイピング | 不可 |
| メルカリ個人アカウントでの事業出品、複数アカウント運用、無在庫出品 | 不可 |
