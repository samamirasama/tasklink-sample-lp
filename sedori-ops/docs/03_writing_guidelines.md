# ライティング規約（出品文面）

対象: Amazon（相乗り出品のコンディション説明・新規カタログ作成時）、ヤフオク!/Yahoo!フリマ、メルカリShops。
テンプレは `templates/listing_*.md`。

## 1. 原則

1. **事実だけを書く。** 型番、サイズ、付属品、保証、コンディションは仕入れ先ページか現物で確認した内容のみ。
2. **購入者の検索語で書く。** タイトルは「ブランド 型番 商品名 主要スペック 数量」の順。装飾語（激安、大人気）は使わない。
3. **不安を先回りして潰す。** 発送日数、梱包方法、保証の有無、返品条件を明記。問い合わせを減らすことが目的。
4. **プラットフォームごとに作り分ける。** Amazonは相乗りが基本で書けるのはコンディション説明のみ。ヤフオク!・メルカリShopsは自由記述なので構成テンプレに従う。

## 2. 禁止・要注意表現

| 区分 | 例 | 理由 |
|---|---|---|
| 優良誤認 | 最高品質、No.1、業界最安、完璧 | 景品表示法 |
| 有利誤認 | 今だけ、残りわずか（事実でない場合）、通常価格○円（根拠のない二重価格） | 景品表示法 |
| 薬機法 | 殺菌、除菌効果で病気予防、痩せる、治る、アンチエイジング | 医薬品的効能の標榜 |
| 知財 | メーカー公式画像・文章のコピー、他出品者の文章コピー | 著作権・商標 |
| 外部誘導 | LINE・自社サイト・他モールへの誘導、連絡先の記載 | 各社規約違反 |
| レビュー | 「高評価をお願いします」「レビューで○○プレゼント」 | Amazon規約違反 |
| 断定保証 | 絶対、必ず、100% | クレームの元 |

## 3. コンディション表記（Amazon新品）

- 未開封・未使用、メーカー保証（あれば期間）を明記。
- 「新品」と書けるのは、メーカー保証が購入者に有効に引き継がれ、パッケージが未開封の場合のみ（Amazonコンディションガイドライン準拠、詳細は公式で確認）。
- 展示品・アウトレット・箱つぶれは新品として出さない。

## 4. 構成テンプレ（自由記述プラットフォーム）

```
【商品名】ブランド 型番 商品名（色・サイズ）
【状態】新品未開封 / メーカー保証○年（保証書同梱）
【内容】本体、付属品一覧
【スペック】主要3〜5項目
【発送】入金確認後○営業日以内、配送方法、追跡番号の有無
【梱包】緩衝材＋段ボール等
【注意】モニターによる色味差、初期不良時はメーカー対応 or 当方対応（プラットフォーム規定に従う）
```

## 5. 品質チェック（copywriter が自己チェック → director が確認）

- [ ] 事実誤りがないか（型番・数量・付属品を仕入れ先ページと突合）
- [ ] 禁止表現が含まれていないか（上表で grep）
- [ ] タイトル文字数がプラットフォーム上限内か（Amazon 全角50文字目安、ヤフオク!65文字、メルカリShops 40文字。実上限は各公式で確認）
- [ ] 発送・返品条件が `business.yaml` と `04_operations_flow.md` と一致しているか
