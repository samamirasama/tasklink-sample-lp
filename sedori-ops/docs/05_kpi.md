# KPI定義

集計は `scripts/kpi_report.py`。目標値は `config/business.yaml: targets`。

## 主要KPI（月次）

| KPI | 定義 | 目標（初期値） | 見る理由 |
|---|---|---|---|
| 売上 | `sales.csv` の sale_price × qty の合計（返品除く） | 300,000円 | 規模 |
| 粗利 | 売上 − 手数料 − FBA費用 − 仕入れ原価 − 送料・梱包 − 返品損 | 60,000円 | 実利益 |
| 粗利率 | 粗利 / 売上 | ≥ 15% | 手数料改定・値下げ耐性 |
| ROI | 粗利 / 仕入れ原価 | ≥ 20% | 資金効率 |
| 在庫回転日数 | 平均在庫金額 / (日次売上原価) | ≤ 45日 | キャッシュフロー |
| 滞留在庫比率 | 45日超在庫の金額 / 在庫総額 | ≤ 20% | 損切り判断 |
| 返品率 | 返品数 / 販売数 | ≤ 3% | 品質・文面の問題検知 |
| 一次返信SLA遵守率 | 24時間以内返信数 / 受信数 | ≥ 95% | 評価維持 |
| リサーチ歩留まり | approved / 調査候補数 | 記録のみ | リサーチ精度の改善 |

## 週次で見るもの

- 承認待ち候補数、発注済み未入荷、入荷済み未出品、価格改定が必要なSKU数、未返信メッセージ数。

## 判断ルール

- 粗利率が2か月連続で目標未達 → カテゴリ配分と仕入れ基準（`roi_min` 等）を見直す。
- 滞留比率が20%超 → 新規仕入れを一時停止し、在庫処分を優先。
- 返品率が5%超 → 該当SKUの出品文面とコンディション表記を再点検。
