## 判断への反映

- `business.yaml` の `selling_platforms.mercari_shops.enabled` は初期値 false（#3, #4 のため）。
- `business.yaml` の `business.handles_used_goods` は初期値 false（#6 のため。許可取得後に true）。
- 利益計算では販売手数料に +0.4pt を織り込んだ既定値を使う（#1）。ただしカテゴリ別実値で上書きすること。
- 楽天仕入れは「排除」ではなく「注意付き」で残す（#7）。大量購入・複数アカウント・ポイント目当ての回し買いは行わない。

## 再確認の手順

1. Amazon: セラーセントラル → ヘルプ →「Amazon出品サービスの手数料」「FBA配送代行手数料」。確認日を `business.yaml` の `fee_rates_verified_on` に記入。
2. メルカリ: 公式ヘルプ「禁止されている行為」「メルカリShops 出店条件」。
3. 古物商: 営業所所在地を管轄する警察署の生活安全課（防犯係）。
4. 特商法: 消費者庁「特定商取引法ガイド」。
5. Keepa / SP-API: 各公式の料金ページ。
