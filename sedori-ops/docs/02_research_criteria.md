# 仕入れ判断基準とスコアリング

閾値はすべて `config/business.yaml` から読む。ここではロジックだけを定義する。

## 1. 候補の必須条件（1つでも外れたら不採用）

1. 法令・規約チェック B1〜B8 をすべて通過
2. 想定粗利率 ≥ `targets.gross_margin_min`
3. ROI ≥ `targets.roi_min`
4. 1個あたり粗利 ≥ `targets.profit_per_unit_min_jpy`
5. 想定回転日数 ≤ `targets.sell_through_days_max`
6. FBA出品者数 ≤ `research.max_fba_sellers`
7. 直近 `price_drop_lookback_days` 日で継続的な値下がり傾向でないこと（Amazonに出品者が増え続けている商品は避ける）

## 2. 利益計算（`scripts/profit_calc.py` が実装）

```
売上            = 想定販売価格
販売手数料      = 売上 × カテゴリ別販売手数料率（referral_fee_by_category、無ければ default）
FBA配送代行     = サイズ区分に応じた金額（fba_fees.csv）
保管料          = monthly_storage_fee_per_unit_jpy × (想定回転日数 / 30)
入庫送料・梱包  = inbound_to_fba_per_unit_jpy + packaging_per_unit_jpy
返品引当        = 売上 × return_rate_assumed
仕入れ原価      = 仕入れ価格（税込） + 仕入れ送料 / 数量
ポイント        = include_points_in_profit が true のときのみ 還元額 × points_haircut を原価から控除
粗利            = 売上 − 販売手数料 − FBA配送代行 − 保管料 − 入庫送料・梱包 − 返品引当 − 仕入れ原価
粗利率          = 粗利 / 売上
ROI             = 粗利 / 仕入れ原価
```

想定販売価格は「現在のカート価格」ではなく、**直近90日の中央値と現在カート価格の低い方**を使う。値崩れに備えるため。

## 3. スコアリング（100点満点、70点以上を「推奨」）

| 観点 | 配点 | 採点方法 |
|---|---|---|
| 収益性 | 30 | ROIが roi_min の1倍=15点、1.5倍=22点、2倍以上=30点（線形補間） |
| 回転 | 25 | 月間推定販売数が min の1倍=12点、2倍=20点、3倍以上=25点 |
| 競合 | 20 | FBA出品者数 1〜2=20、3〜4=15、5〜6=10、7〜8=5 |
| 価格安定性 | 15 | 90日変動係数 ≤10%=15、≤20%=10、≤30%=5、それ以上=0 |
| リスク | 10 | 出品規制なし・請求書取得容易・メーカー転売禁止なし で各3〜4点 |

減点: 季節商品で販売ピークまで60日以上ある(−10)、Amazon本体が出品中(−15。本体が在庫切れの期間限定案件は別途判断)、直近30日に新規出品者が3社以上増加(−10)。

## 4. リサーチの手順（researcher が実行）

### 4-1. Keepa 利用時（`tools.keepa.enabled: true`）

1. 対象カテゴリ・仕入れ先セールを事業主から受け取る。
2. Keepa Product Finder 等で、ランキング上位・FBA出品者数少・価格安定の条件で候補を抽出（条件は上記閾値）。
3. 候補ごとに仕入れ先で現在価格・在庫・購入制限・規約を確認（URLと確認時刻を記録）。
4. `profit_calc.py` で試算し、スコアリング。
5. `data/candidates.csv` に追記し、`templates/research_report.md` 形式で報告。

### 4-2. Keepa 未契約時（目視確認モード）

1. Amazon商品ページの「売れ筋ランキング」「出品者一覧」を事業主が目視確認し、数値をエージェントに渡す。
2. 月間販売数は推定できないため、`回転` スコアは上限12点までとし、報告に「推定精度: 低」と明記。
3. 目視モードでは1SKUの仕入れ数量を `max_per_sku_jpy` の50%以内に抑える。

## 5. リサーチで捏造してはいけないもの

- ランキング、出品者数、月間販売数、価格履歴。取得できなければ「未取得」と書く。
- 「売れる」「人気」といった評価語を、数値の裏付けなしに書かない。
