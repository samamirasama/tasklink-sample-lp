# メルカリShops 出品文面テンプレ（新品）

前提: メルカリShopsの出店審査に通過していること（`business.yaml: selling_platforms.mercari_shops.enabled: true`）。
フリマアプリ「メルカリ」個人アカウントでの事業出品は規約で禁止されているため、このテンプレを個人アカウントに流用しない。

## 商品名（40文字以内）
`{ブランド} {型番} {商品名} {色/サイズ} 新品`

## 商品説明

```
{ブランド} {型番} {商品名}（{色/サイズ}）の新品未開封品です。

■ 状態
新品未開封 / メーカー保証{○年}（保証書同梱）

■ 内容
本体、{付属品}

■ スペック
・{項目1}
・{項目2}
・{項目3}

■ 発送
ご購入から{1〜2}日以内に発送します（{配送方法}、匿名配送対応）。

■ ご注意
・外箱に輸送時の軽微なスレがある場合があります。
・初期不良はメーカーサポートをご案内します。
```

## 設定メモ

- 販売手数料 `fee_rate`（初期値10%）で floor_price を再計算してから価格を決める。
- 在庫連動: 同一在庫を複数販路に出す場合、`inventory.csv` の qty_available を売れた時点で即更新し、売り越し（無在庫状態）を作らない。
