# 購入者: 配送に関する問い合わせ

## 発送前
```
{購入者名} 様

このたびはご購入ありがとうございます。
ご注文の「{商品名}」は {発送予定日} に発送予定です。
発送後に追跡番号をお知らせいたします。

{店舗名}
```

## 発送済み
```
{購入者名} 様

ご連絡ありがとうございます。
「{商品名}」は {発送日} に {配送業者} にて発送済みです。
追跡番号: {追跡番号}
お届け予定: {予定日}（配送状況により前後する場合があります）

{店舗名}
```

## FBA（Amazon倉庫発送）の場合
```
{購入者名} 様

ご連絡ありがとうございます。
本商品はAmazonの配送センターから発送されます。配送状況は「注文履歴」からご確認いただけます。
お届け予定日を過ぎても届かない場合は、Amazonカスタマーサービスでも迅速に対応いただけます。

{店舗名}
```

記録: `contacts.csv` category=shipping
