# 購入者: 商品状態のクレーム（破損・不良・相違）

原則: 謝罪 → 事実確認（写真依頼） → 選択肢提示（プラットフォーム規定の範囲） → 記録。反論や責任転嫁をしない。
返金・交換の**確定**は事業主が行う（`escalate_to_owner_when`）。

## 一次返信（写真依頼）
```
{購入者名} 様

このたびはご不便をおかけし、誠に申し訳ございません。
状況を正確に確認させていただきたく、お手数ですが以下をお送りいただけますでしょうか。

1. 商品の該当箇所の写真
2. 外箱・梱包の状態がわかる写真
3. 到着日

確認後、交換または返金のご案内を {SLA時間} 以内にいたします。

{店舗名}
```

## 二次返信（対応提示・事業主承認後）
```
{購入者名} 様

写真をお送りいただきありがとうございました。
確認の結果、{当方の梱包不備 / 輸送時の破損 / 初期不良} と判断いたしました。
以下のいずれかをお選びください。

A. 全額返金（返送{要/不要}）
B. 同一商品との交換（在庫{有/無}）

ご希望をご返信いただければ、{プラットフォーム}の手続きに沿って進めます。

{店舗名}
```

## エスカレーション条件
- 真贋・偽物の指摘 → 即事業主へ。返信は「確認のうえご連絡します」のみ。
- 2往復目以降で解決しない → 事業主へ。
