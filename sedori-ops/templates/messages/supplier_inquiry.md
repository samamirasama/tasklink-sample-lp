# 仕入れ先（EC店舗・メーカー）への連絡

## 在庫・数量制限の確認
```
{店舗名} ご担当者様

お世話になっております。{屋号}の{氏名}と申します。
貴店で販売されている「{商品名}（{型番}）」について、以下をお伺いしたくご連絡いたしました。

1. 現在の在庫数と、1回の注文での購入可能数量
2. 事業者宛の請求書（宛名・登録番号入り）の発行可否
3. まとめ買い時の価格や送料の条件

お手数をおかけしますが、ご回答いただけますと幸いです。

{屋号} {氏名}
{電話番号} / {メール}
```

## 入荷不備（数量不足・破損）の連絡
```
{店舗名} ご担当者様

お世話になっております。注文番号 {注文番号} の件でご連絡いたします。
{到着日} に受領しましたが、以下の不備がございました。

・{数量不足: ○個注文に対し○個到着 / 外箱破損 / 型番相違}

写真を添付いたします。{不足分の発送 / 交換 / 返金} のご対応をお願いできますでしょうか。

{屋号} {氏名}
```

## 交渉（数量割引・卸条件）
→ 事業主がエスカレーション対象（`escalate_to_owner_when`）。communicator は下書きのみ作成し、送信前に事業主が確認する。
