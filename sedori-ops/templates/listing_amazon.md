# Amazon 出品文面テンプレ（相乗り出品・新品）

Amazonの相乗り出品で出品者が書けるのは主に「コンディション説明」（全角約500文字以内目安、実上限は公式で確認）です。
新規カタログ作成が必要な場合のみ、タイトル・箇条書き・商品説明を作成します。

## コンディション説明（新品）

```
新品未開封品です。メーカー保証（○年 / 保証書同梱）付き。
Amazon倉庫より迅速に発送いたします（FBA）。
外箱に輸送時の軽微なスレが生じる場合があります。
初期不良の際はAmazonの返品ポリシーに沿って対応いたします。
```

## 新規カタログ作成時

### タイトル（全角50文字目安）
`{ブランド} {型番} {商品名} {主要スペック} {色/サイズ} {数量}`

### 商品の仕様（箇条書き5点）
1. 【用途】…
2. 【スペック】…
3. 【付属品】…
4. 【サイズ・重量】…
5. 【保証・注意】…

### 商品説明
（事実のみ。`docs/03_writing_guidelines.md` の禁止表現を含めない）

### 検索キーワード（バックエンド）
（タイトルと重複しない同義語・表記ゆれ。ブランド名の他社名は入れない）

## 出品前チェック

- [ ] コンディションガイドライン準拠（未開封・保証引き継ぎ）
- [ ] 禁止表現なし
- [ ] 型番・付属品を仕入れ先ページと突合
- [ ] `inventory.csv` に floor_price（下限価格）を登録済み
