# ヤフオク! / Yahoo!フリマ 出品文面テンプレ（新品）

## タイトル（65文字以内）
`【新品未開封】{ブランド} {型番} {商品名} {色/サイズ} 保証書付 送料無料`
（「送料無料」は実際に出品者負担のときのみ）

## 商品説明

```
【商品名】{ブランド} {型番} {商品名}（{色/サイズ}）
【状態】新品未開封。メーカー保証{○年}（保証書同梱）。
【内容】本体、{付属品}
【スペック】
・{項目1}
・{項目2}
・{項目3}
【発送】ご入金確認後{1〜2}営業日以内に発送。{配送方法}（追跡番号あり）。
【梱包】緩衝材で保護のうえ段ボールに入れて発送します。
【注意事項】
・モニター環境により色味が異なる場合があります。
・初期不良はメーカーサポートをご利用ください（{または}到着後○日以内にご連絡いただければ対応します）。
・ノークレーム・ノーリターンの記載は行いません（ガイドライン準拠・トラブル防止のため）。
【事業者情報】特定商取引法に基づく表示はプロフィール欄をご確認ください。
```

## 設定メモ

- 開始価格 = floor_price 以上（値下がり損を防ぐ）。即決価格 = 想定販売価格。
- 出品期間は回転目標に合わせる（新品なら3〜5日で回すのが目安、根拠は自店の実績で更新）。
