# 価格選択テストの設計（試用終了時）

- 目的：口頭の支払意思ではなく、**提示した選択肢から実際に選んだ結果**を記録する。少人数のため傾向把握に限る。
- 実施：試用終了面談の最後、他の質問が終わってから。価格の話を先にすると、試用中の行動に影響する。

## 1. 提示する3案（文言は固定し、全員に同じ順序で見せる）

| 案 | 内容 | 表示価格（仮） |
|---|---|---|
| A 無料のまま | 保存・見返し・完了/保留/不要・書き出し。件数上限（例：200件）あり | ¥0 |
| B 買い切り | Aの全機能＋件数無制限＋画像のOCR検索（端末内） | ¥1,200（1回） |
| C 月額 | Bの全機能＋将来の分類補助（AI）。いつでも解約可 | ¥300/月 |

- 価格は仮。比較対象（GoodLinks ¥1,500買切、Anybox ¥300/月・¥6,000買切、Raindrop Pro ¥300/月）と同じ帯に置く。
- 試用者を2群に分け、B/Cの価格を一段変えて提示する（例：B ¥1,800、C ¥480）。人数が少ないので差の検定はしないが、価格で選択が動くかの手がかりにする。

## 2. 聞き方（固定文）
> 「この試作品を今後も使えるとしたら、次の3つのうちどれを選びますか。実際に支払いは発生しません。選ばない理由も教えてください。」

- 選択を記録したあとに「なぜ」を聞く。先に理由を聞かない。
- 「どれも選ばない（やめる）」も選択肢として明示する。

## 3. 記録（1人1行）

| 参加者ID | 提示群（1/2） | 選択（A/B/C/やめる） | 理由（要約） | 試用中の整理率 | 7日後利用 |
|---|---|---|---|---|---|

## 4. 判定の目安（事前に固定）
- BまたはCを選んだ人が1人もいなければ、「価格の正当性なし」として課金設計を見直す（無料＋寄付、または買い切りのみ等）。
- Cを選ぶ人がBより多い場合のみ、月額を主案にする。そうでなければ買い切りを主案にする。
- 選択理由に「終了してもデータが残るなら払う」が出れば、ローカル保存・書き出しを訴求点に加える。

## 5. 限界
- 無料の選択肢を提示すると無料に寄りやすい。実決済ではないため、公開後の転換率の予測には使えない。
- 人数が少なく、群分けの比較は傾向のみ。
