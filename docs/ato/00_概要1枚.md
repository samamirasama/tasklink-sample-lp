# ATO（仮称）企画 概要（1枚）

- 日付：2026年10月2日（木）／ 状態：競合・技術・費用の調査完了、需要検証は未着手
- 詳細：`01_結論と評価.md`。本紙は関係者・開発候補者への共有用。

## 何を作ろうとしているか
SNSやWebで見つけた「行きたい店・買いたい物・やりたいこと」を、その場では何も決めずに共有シートで1か所に貯め、週1回まとめて見返して「開く・完了・保留・不要」のどれかを選ぶ iPhone アプリ。保存件数を増やすのではなく、実行するか手放すかを決めさせることが目的。

## 判定
**対象・仕様を変えて、開発前の検証に進む。開発GOではない。** 技術面の確度は高、需要・事業面は低。

## 根拠（要点）
- 技術：共有拡張→共有コンテナに即保存→本体で取得・整理、はAppleの公式資料に沿う。端末内OCRと端末内LLM（iOS 27で8,192トークン）は無料で使える。
- 競合32件：「保存時に何も決めない」＋「未処理を少数ずつ自動で再提示」＋「完了・保留・不要で手放す」の3点セットを持つ製品は確認できなかった。ただし近接機能は多数あり、模倣は容易。
- 無料代替：Apple リマインダーは共有保存・日時通知・無料に加え、iOS 26からApple Intelligenceが本文から候補を提案する。ATOとの差は「日時を決めなくても週次で再提示され、不要で手放せる」点だけ。
- 価格：月¥300帯（Raindrop Pro、Anybox、Cubox、Bear）は保存無制限・同期・検索を含む。ATOの¥300〜500仮説は同じ帯で機能量が劣る。
- 費用：AI分類の原価は1件あたり約0.4〜1円。採算の鍵は原価ではなく「払う人数」と「継続」。
- 市場：Pocketは利用者3,000万人超でも2025年7月に終了。終了への不信（データ消失）は乗り換え層の明確な不満で、「ローカル保存・書き出し容易」は訴求点になり得る。

## MVPに入れるもの／外すもの
- 入れる：共有保存（URL・画像・テキスト）、一覧、元情報を開く、完了・保留・不要と取り消し、週次レビュー、書き出し・全削除、手動3分類（行く／買う／やる）、任意の週次通知（既定オフ）。
- 外す：AI分類、5分類、時間別再提示、同期・アカウント、スクショ自動取り込み、外部AI。

## 次の3つ（順番）
1. 代替A：Apple リマインダーで「週次に見返して手放す」運用を5人・2週間（開発ゼロ）。
2. ヒアリング10〜20人（`05` のキット）。
3. 実機技術検証（`06`）→ 試作品（`07`）→ 5〜8人で2〜3週間試用 → 判断（`01` 7章の条件）。

## 体制と制約（2026-10-02 回答）
代替Aは実施可。対象者2〜3人で小さく始める。開発用Macなし（Windows）のため、まずショートカット版（コード不要）、次にExpo＋EAS（Mac不要でTestFlight提出可）の順で進める。名称「TaskL」はGoogle Playに同名のタスク管理アプリがあり要再確認。未確認：検証用iPhoneの有無・機種、開発担当、Developer Program加入時期。
