# 試用者向け手順書（試作品の少人数試用、2〜3週間）

- 作成日：2026年10月2日（木）
- 対象：試用に協力いただく5〜8人。運営側は `03_検証計画.md` 6.4 と `07_MVP仕様書.md` を参照。
- 前提：試作品の配布は TestFlight を使う（Apple Developer Program 加入が必要。配布手順は運営側で別途確認）。

## 1. はじめに（運営から試用者へ）
- これは完成品ではなく、使い勝手を確かめるための試作品です。動かない点があればそのまま教えてください。
- 保存した内容は、あなたのiPhoneの中にだけ保存されます。運営に自動で送られることはありません。
- 面談のときに、アプリの「設定→記録を書き出す」で出力した**操作の記録**（何件保存した、いつ見返した、など）だけをお渡しください。保存した内容そのもの（URL・画像・本文）は含まれません。
- いつでもやめられます。やめる場合は「設定→すべて削除」で消せます。

## 2. インストール（一工程ずつ）
1. App Store で「TestFlight」を検索し、インストールする。
2. 運営から届いた招待リンク（メールまたはメッセージ）を開く。
3. TestFlight の画面で「インストール」を押す。
4. ホーム画面にアプリが追加されたら開く。初回の説明文を読んで「はじめる」を押す。
5. 通知の許可を求められたら、**どちらを選んでも構いません**（通知なしでも使えます。選んだ内容は記録されます）。

## 3. 共有シートに追加する（初回のみ）
1. Safari で何かのページを開き、下の「共有」ボタン（四角から矢印が出たマーク）を押す。
2. アプリの並びを右にスクロールして「その他」を押す。
3. 「編集」を押し、試作品の名前の横の「＋」を押して「よく使う項目」に入れる。「完了」を押す。
4. 次回から共有シートの先頭近くに表示されます。

## 4. ふだんの使い方（2〜3週間）
- SNSやWebで「あとで行きたい・買いたい・やりたい」と思ったものがあれば、**その場で分類や日付を決めず**、共有ボタン→試作品を選ぶだけで保存してください。
- Instagram：投稿の紙飛行機マーク→「共有先」→試作品。X：共有→「他の方法で共有」→試作品。YouTube：共有→「その他」→試作品。
- スクショも同じです。写真アプリで共有→試作品。
- 保存できなかった、時間がかかった、どれを選べばいいか迷った、などがあればメモしておいてください（面談で聞きます）。
- **無理に保存件数を増やさないでください。** ふだん通りで構いません。

## 5. 週に1回の見返し
1. 週に1回（曜日は自由。通知を許可した人には設定した曜日に届きます）、アプリを開き「今週の見返し」を押す。
2. 1件ずつ表示されます。それぞれについて、次のどれかを押してください。
   - **開く**：元のページや画像を見る。
   - **完了**：もう行った・買った・やった。
   - **保留**：まだ決めない。次回以降にまた出ます。
   - **不要**：もういらない。消しても困らない。
3. 「今日はここまで」で途中でやめても構いません。
4. 「不要」にしたものは「設定→不要にしたもの」から30日間は戻せます。

## 6. 面談の前に
1. 「設定→記録を書き出す」を押し、出てきたファイルを運営に共有（AirDrop またはメール）する。
2. 面談（15分）では、保存しなかったものとその理由、迷った操作、通知の感じ方を聞きます。良かった点より困った点を優先して教えてください。

## 7. 試用の終わりに
- 3つの案（無料のまま／買い切り／月額）を見せて、「自分ならどれを選ぶか」を**実際に選んで**いただきます（支払いは発生しません）。詳細は `kit/pricing_test.md`。
- 続けて使いたい場合はそのまま使えます。やめる場合は「設定→すべて削除」で消せます。

## 8. 困ったとき
- アプリが開かない、保存できない：スクショを撮って運営に送ってください（スクショに個人情報が写る場合は送らなくて構いません）。
- 連絡先：（運営が記入）
